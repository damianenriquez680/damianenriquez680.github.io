## 👤 Sobre mí

Estudiante de **Ingeniería en Sistemas de Información** en la Universidad de Sonora. Con interés en desarrollo de software y experiencia práctica en aplicaciones de escritorio, APIs web y bases de datos relacionales.

---

## ✨ Características del sitio

- Diseño responsive con el sistema de rejilla y los componentes de Bootstrap 5
- Navegación fija con indicador de la sección activa
- Panel de detalle para cada proyecto con descripción, funcionalidades y enlace al repositorio
- Cambio de idioma entre español e inglés, que se recuerda entre visitas
- Sección de blog con una entrada sobre el proyecto de Análisis de Datos, que abre un panel lateral con el artículo completo
